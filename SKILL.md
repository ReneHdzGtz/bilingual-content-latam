## MODULE 1 — Localization Engine

**Trigger:** User has English content and needs Spanish adaptation for LATAM audiences.

### Step 1: Localization Brief
Ask if not provided:
- **Source content** (paste the text or describe it)
- **Target country/region** (Mexico / Colombia / Argentina / Generic LATAM / All)
- **Audience** (general consumer / technical / professional / crypto-native / youth)
- **Tone** (formal / conversational / direct / technical / aspirational)
- **Platform** (Twitter/X / LinkedIn / Instagram / email / website / ads)
- **Any terms to preserve in English?** (brand names, technical terms, etc.)

### Step 2: Localization vs. Translation

**Translation** (word-for-word, avoid this for marketing):
- EN: "We're building the future of finance."
- Literal ES: "Estamos construyendo el futuro de las finanzas."
- Problem: Sounds like it was written by a machine. No LATAM person speaks like this.

**Localization** (culturally adapted, use this):
- MX version: "Estamos transformando el sistema financiero desde adentro."
- CO version: "Construimos las herramientas que el sistema no quería que existieran."
- ARG version: "El futuro de las finanzas lo estamos construyendo nosotros, no los bancos."

**Rule:** Every piece of LATAM content must sound like it was written by a native speaker from that region — not translated from English.

### Step 3: Localization Checklist
Before delivering any localized content, verify:
- [ ] No "Spanglish" constructions (English sentence structure with Spanish words)
- [ ] Idioms are regional, not generic ("cool" ≠ "cool" in all countries — see country guide below)
- [ ] Formality level matches the platform (tú vs. usted — see guide below)
- [ ] Numbers formatted correctly (1.000 vs 1,000 — varies by country)
- [ ] Currency references are localized if relevant
- [ ] Cultural references land for the target country (not all LATAM is the same)
- [ ] CTA is natural in the target market's communication style

### Tú vs. Usted Guide by Country and Context

| Country | General | Professional | Digital/Ads |
|---|---|---|---|
| Mexico | tú (mostly) | usted (formal B2B) | tú |
| Colombia | usted (even casual) | usted | usted or tú depending on brand |
| Argentina | vos (not tú) | usted | vos |
| Chile | tú / usted (mixed) | usted | tú |
| Peru | usted (conservative) | usted | tú or usted |
| Generic LATAM | tú (safest default) | usted | tú |

**Argentina note:** Always use "vos" not "tú" — "tú" sounds foreign to Argentines. Conjugation changes: "tú tienes" → "vos tenés", "tú eres" → "vos sos".

## MODULE 2 — Bilingual Campaign Strategy

**Trigger:** User needs to plan a campaign that works in both English and Spanish.

### Step 1: Campaign Architecture for Bilingual Markets

```
BILINGUAL CAMPAIGN FRAMEWORK
──────────────────────────────
Campaign Name: [Name EN] / [Nombre ES]
Objective: [Same across both languages]
Target market EN: [US / Global / Canada]
Target market ES: [MX / CO / LATAM / US Hispanic]
Duration: [dates]
Primary platforms: [by language and market]
```

### Step 2: Language Separation Strategy

**Option A — Fully Separate Campaigns (recommended for different target markets):**
- English campaign: US/global content, US cultural references, USD pricing
- Spanish campaign: LATAM-specific content, local cultural anchors, local currency

**Option B — Bilingual on Same Channel:**
- Alternate posts EN/ES on the same account (works for X/Twitter)
- Post at optimal times per audience (Mexico: 8–10am CST / US East: 9–11am EST)
- Tag language: "(ES) / (EN)" as first word/emoji if mixed feed

**Option C — Bilingual in Single Piece:**
- For ads: run A/B with same creative, different copy — let data decide
- For LinkedIn: write key post in EN + Spanish version as first comment
- For email: segment list and send language-matched versions

### Step 3: Content Calendar Structure for Bilingual

| Day | English Content | Spanish Content | Platform |
|---|---|---|---|
| Mon | [Topic EN] | [Tema ES — adapted] | X/Twitter |
| Tue | [Topic EN] | [Tema ES] | LinkedIn |
| Wed | [Topic EN] | [Tema ES] | Instagram |
| ... | | | |

**Rule:** Never post the exact same content in both languages on the same day on the same account — it signals low effort. Create distinct pieces that serve each audience.

## MODULE 3 — Country-Specific Content

**Trigger:** User needs content for a specific LATAM country.

### Mexico 🇲🇽

**Communication style:** Direct, warm, slightly informal. Humor and irony work well. Mexicans respond to authenticity over polish.

**Idioms / expressions that land:**
- "A todo dar" / "Está de pelos" = excellent
- "No te rayes" = don't overthink it
- "Híjole" = expression of surprise
- "Chido/a" = cool
- "Está cabrón" = it's tough (casual register only)

**Avoid:** Overly formal corporate language — it sounds like a government document and creates distance.

**Cultural touchpoints:** Football (fútbol, Liga MX, Selección Nacional), independence narrative, entrepreneurship pride, family-first messaging, irreverence toward institutions.

**Crypto/fintech context:** Mexico has one of the highest remittance markets globally — financial inclusion and cross-border payments messaging resonates strongly. Crypto Twitter MX is highly active.

---

### Colombia 🇨🇴

**Communication style:** Warmer and more formal than Mexico. "Usted" is standard even between friends in many regions. Content should feel respectful but approachable.

**Idioms / expressions:**
- "Parce" / "Parcero" = friend/buddy (Bogotá, Medellín)
- "Bacano/a" = cool, great
- "¿Qué más?" = how's it going (greeting)
- "Chimba" = awesome (informal, Medellín) — use carefully in formal contexts
- "Pilas" = be careful / heads up

**Cultural touchpoints:** Strong entrepreneurship culture (especially Medellín), national pride, innovation narrative, coffee culture. Colombians respond well to success stories from local entrepreneurs.

**Crypto context:** Growing crypto adoption, significant remittance use case, vibrant developer community in Bogotá.

---

### Argentina 🇦🇷

**Communication style:** Direct, sometimes blunt, highly educated audience. Sarcasm and irony are norms. Very skeptical of hype — Argentines have been burned by economic crises and distrust institutions deeply.

**Critical grammar:** Always use "vos" and voseo conjugation. Never "tú."
- "Tenés" not "tienes"
- "Sos" not "eres"
- "Poné" not "pon"

**Idioms / expressions:**
- "Copado/a" = cool, awesome
- "Boludo/a" = (varies from insult to term of endearment based on context — use carefully)
- "Buena onda" = good vibe
- "¿Todo bien?" = how are you doing?
- "Che" = hey / mate

**Cultural touchpoints:** Economic hardship as lived experience (inflation, peso devaluation) — crypto as protection narrative hits harder here than anywhere. High crypto adoption rate, strong developer community, extremely skeptical of "get rich quick" framing.

**Crypto context:** Argentina has one of the highest per-capita crypto adoption rates globally precisely because of economic instability. Dollar-denominated messaging (USDC, DAI) resonates strongly.

---

### Generic LATAM (when targeting the full region)

**Safe defaults:**
- Use tú (not vos, not usted)
- Avoid country-specific slang
- Use neutral Spanish with no strong regional accent in text
- Use USD as reference currency
- Focus on shared values: financial freedom, distrust of traditional banks, family security, technological empowerment

**What unites LATAM crypto audiences:**
- Remittances: sending money across borders is a universal pain point
- Dollar access: stablecoins as protection from inflation
- Financial exclusion: large unbanked population who can access DeFi directly
- Mobile-first: most LATAM users are on mobile — write accordingly

## MODULE 5 — Copy Review & Quality Check

**Trigger:** User has Spanish content and wants a review before publishing.

### Quality Review Framework

When reviewing Spanish marketing content, check against these 8 criteria:

1. **Naturalness** — Does it sound like a native speaker wrote it, or like Google Translate?
2. **Regional appropriateness** — Is the dialect/register right for the target country?
3. **Tú/Usted/Vos** — Is the form of address consistent and correct for the region?
4. **Slang / Idioms** — Any expressions that could be misunderstood in another region?
5. **Tone match** — Does the formality level fit the platform and audience?
6. **CTA clarity** — Is the call to action natural and action-oriented?
7. **Cultural sensitivity** — Any references that could land wrong in the target market?
8. **Brand voice** — Does it match the established brand tone, not just translate words?

### Output format for review:

```
COPY REVIEW — [Title / Platform]
─────────────────────────────────
ORIGINAL TEXT:
[Paste content]

ISSUES FOUND:
1. [Line or phrase] → [Problem] → [Suggested correction]
2. [Line or phrase] → [Problem] → [Suggested correction]

REVISED VERSION:
[Corrected, localized copy]

NOTES:
[Any context-specific recommendations]
```

## General Quality Rules

1. **Never deliver a literal translation for marketing content** — always ask what the content is trying to achieve and adapt accordingly.
2. **Argentina, Mexico, and Colombia are three different markets** — don't assume what works in one works in all.
3. **When in doubt about slang**, use neutral LATAM Spanish — regional slang that misses is worse than generic copy.
4. **Crypto LATAM audiences are sophisticated** — don't oversimplify. They've lived the economic problems that crypto solves.
5. **Mobile-first always** — 78%+ of LATAM internet use is on mobile. Write short sentences. Break paragraphs. Use emojis where natural.
6. **Test both languages on your metrics** — often the Spanish version outperforms EN in LATAM even for "bilingual" audiences.
